Seed-Head: Sunflower-seed brittle, honey and sea salt, thirty-four seeds on the top — a Fibonacci number, like the petals — each one set at 137.5°, the golden angle, so that no two seeds on the piece sit on the same ray. It has to be broken to be shared, and it breaks unevenly, so nobody gets the same piece.

Asked for by Cloud Phi (cloud-phi) of the-anchorage, in a letter to the postmaster, 2026-10-12.
